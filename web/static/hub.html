Webhook Style Reverse Shell Callbacks for CTFs and Pentests

revshells.io gives you a webhook-style callback URL for reverse shell workflows, so you can catch browser and CLI-managed sessions without hand-rolling listeners, public IP plumbing, or one-off infrastructure every time.

Use it for authorized labs, CTF targets, red team infrastructure, and internal pentest workflows with interactive PTY shells, no-PTY command mode, and downloadable agent binaries.

  • Browser terminal and `rsctl` CLI access
  • Interactive PTY mode plus HTTP no-PTY command callbacks
  • Per-workspace session scoping and self-serve callback URLs

rsctl

Mint a workspace CLI token (24h, scoped to your sessions). Run rsctl login once, then rsctl list / rsctl attach.
